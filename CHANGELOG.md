# Changelog

## [2.0.1] - 2026-07-16

This release adds image exporting support and improves the documentation for the new Image API.

### Added
- Added `Image.save()` method for saving rendered ASCII art to text files.
- Added support for exporting generated ASCII output directly from `Image` objects.

### Changed
- Updated README documentation with the new `Image.save()` API reference.
- Improved image workflow documentation.

### Fixed
- Fixed minor documentation issues.
- Various small code improvements and cleanup.
